# Emberworks player documentation

Curated player guide for the development Emberworks mod, Hytale0.7.2. This repository contains documentation and reviewed web media only. No mod binaries, saves, raw captures or internal engineering records are included.

Build with Python3 and `pip install -r requirements-docs-lock.txt`, then `python -m mkdocs build --strict`. Preview with `python -m mkdocs serve` and inspect the printed URL. Documentation deployment is separate from any mod release.

The source/asset license and required notices are retained. Human sound/visual acceptance, real multiplayer and full survival acquisition remain incomplete; the guide explains the supported development scope.
