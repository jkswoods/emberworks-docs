# Development changes

## 0.3.0-dev · Hytale 0.7.2

Current development work includes factory tiers and native inventory controls with Auto recipe selection; 106 authored processing recipes; finite carbon/Cobalt/water stores; conservative timber secondary output; exact/prefix sorting and crate locks; two native Fieldcraft patterns; direct native water intake/finite discharge; and held Flux Pack charging/returns.

The current held-pack build also fixes the native CustomUI metadata display failure while preserving authoritative inventory metadata. Native charged movement, reload and supported retained-result recovery are exercised. Audio uses original connected ElevenLabs-generated assets with state-driven bindings; human listening and multiplayer acceptance remain incomplete.

No public mod release has been published. The [support status](installation.md) and [known limits](troubleshooting.md) describe the development scope.
