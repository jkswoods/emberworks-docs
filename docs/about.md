# About Emberworks

Emberworks is an independent industrial automation mod for Hytale. Its original machine art, Emberworks forge logo and guide banner are distinct from Hytale's corporate branding. This project is not an official Hytale or Mekanism release.

The logo/banner are original generated Emberworks brand artwork. Gameplay screenshots show Hytale and the mod running natively. Existing stock item/block names identify the installed game's content; its game assets are not distributed as standalone art in this documentation.

The project retains required source and license notices for the reference material it uses. See [third-party notices](third-party-notices.md) and the documentation repository's license. Personal saves, internal plans, verification reports and raw captures are excluded from the public guide.
