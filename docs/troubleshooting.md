# Troubleshooting and known limits

| Symptom | Check |
|---|---|
| Machine page does not open | Correct configured Use action, ownership, distance and actual block. Ordinary Use input still needs acceptance; an operator can use `/emberworks x y z`. |
| Waiting for Flux | Resume source and receiver, supply charcoal, inspect world-axis faces, gaps, owner and loaded area. More lanes can exhaust a small supply. |
| Output full | Make room for every result, including bark/secondary outputs. Auto output needs a valid route and destination space. |
| Recipe will not start | Correct input IDs/quantities, selected pattern, finite media and Flux. Auto cannot invent an unavailable ingredient. |
| Media will not recover | Pause; only whole unreserved carrier quantities can return to the held slot. Paid batches keep their reserve. |
| Crate rejects a stack | It must be a supported plain production material. Customized/worn items and charged packs cannot enter aggregate storage. Use Deposit for a new material kind. |
| Pump/Floodgate does nothing | Supported Lab adapter, owner present, valid below-cell, full-transaction water/Flux room. Other fluids, solids and occupied discharge cells refuse. |
| Plinth will not charge | Resume, hold one valid Flux Pack near its deck and provide Flux. The initial slice does not charge every carried/equipped item. |
| Return held energy refuses | Pause the plinth. Check pack energy and station room. |
| Recovery refuses admission | Stop and retain the complete save/JAR pair and logs privately. Restore a known matched backup or have the maintainer inspect it; do not delete receipts, reset the factory or mix independent saves. |

This is a development guide rather than a production survival-server release. The controlled native durability checks cover specific supported paths; independent provider/world/lifecycle permutations remain incomplete. Water and charging currently require the supported copied Lab. Normal crafting/unlocks and the complete survival acquisition journey are still under acceptance. Native sound files and event bindings exist, but human listening/editor/visual approval and real second-client ownership/contention/audience checks remain pending.

Representative native loops and reloads do not establish every tier, every indexed compatibility recipe or an arbitrary inventory provider. Larger fluid/chemical networks and advanced machine chains are future work. There is no public mod release/download or public issue tracker yet. Keep personal saves, logs and account details out of any public report.
