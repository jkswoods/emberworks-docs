# Processing recipes

The shipped default catalog contains **106 processing recipes**. Base duration counts loaded work at 0.1 seconds per step. Modules, parallel lanes, Flux starvation and server configuration affect observed timing; an active batch retains its saved contract. Survival acquisition and complete external compatibility are still under acceptance.
