# Tiers, modules and installers

| Tier | Worker lanes | Worker Flux capacity | Reservoir Flux | Crate material capacity |
|---|---:|---:|---:|---:|
| Standard | 1 | 20,000 | 200,000 | 256 |
| Foundry | 3 | 60,000 | 800,000 | 1,024 |
| Refined | 5 | 100,000 | 3,200,000 | 4,096 |
| Precision | 7 | 140,000 | 12,800,000 | 16,384 |
| Resonant | 9 | 180,000 | 51,200,000 | 65,536 |

These are shipped defaults. Workers include the Mill, Hearth, Crucible, Grinder, Splitter, Press, Forge and Assembler. Each lane retains its own paid recipe/work. More lanes need enough input, output room and power. Pump, Floodgate, Dynamo, conduits and Charging Plinth currently have no worker tier expansion.

Hold the **next** crafted tier installer and use the machine's Configure upgrade control. Ownership, expected tier, actual block and complete inventory result must agree. A tier mismatch or unavailable return space refuses. Do not substitute a higher-tier installer for the next required tier.

Speed and Efficiency each have a native upgrade slot holding up to **four modules**. Use actual inventory moves and inspect the displayed level. Speed increases work demand; ensure the network can supply it. Module changes do not reset the saved paid recipe or create materials.

For removal, return materials and modules and deal with stored Flux through the explicit maintenance controls first. Keep a paired backup before replacing builds or attempting migration. Survival crafting of the entire installer progression and the full native tier/provider matrix remain under acceptance.
